# אטלס GNSS

כלי דפדפן למעקב אחרי מקלט ה-GNSS של הטלפון ולניתוח לוגים של GNSS. מותאם לטלפון, עובד גם במחשב.

## מה יש בו

**מעקב חי** (Geolocation API של הדפדפן)
- מיקום WGS84, דיוק, גובה, מהירות וכיוון. כל פתרון מוצג ברגע שמגיע, בלי מטמון.
- קצב העדכון בפועל, פיזור הפתרונות (RMS) וגרפים חיים.
- ייצוא הסשן ל-CSV, ואפשרות להשאיר את המסך דולק.

**ניתוח לוג** (הקובץ נקרא רק בדפדפן ולא נשלח לשום מקום)
- מפת שמיים ו-C/N₀ לכל אות, מי בשימוש בפתרון, מסלול, וניגון לאורך זמן.
- פורמטים נתמכים:
  - [GPSTest](https://github.com/barbeau/gpstest) ו-[GnssLogger](https://github.com/google/gps-measurement-tools): רשומות `Status`, `Fix`, `Raw` ו-`NMEA`
  - קובצי NMEA 0183 ממקלטים חיצוניים (u-blox וכו׳), כולל מזהי אותות של NMEA 4.1

> דפדפנים לא חושפים נתוני לוויינים בזמן אמת. לכן מפת השמיים זמינה רק דרך לוג.

## פרטיות ואבטחה

- **אין שרת:** האתר הוא קבצים סטטיים. המיקום נשמר רק בזיכרון של הדף ונמחק כשסוגרים או מרעננים אותו. אין עוגיות, אין אנליטיקס ואין סקריפטים של צד שלישי.
- **מה יוצא מהמכשיר, ורק אחרי פעולה מפורשת שלך:**
  - **מפה:** כבויה כברירת מחדל. כשמפעילים אותה, נשלחות ל-OpenStreetMap בקשות לאריחי האזור שמוצג. ההסכמה נפרדת לכל לשונית ותקפה רק עד סגירת הדפדפן.
  - **הכפתור "מפה":** פותח את Google Maps עם הקואורדינטות.
  - **"קובץ לדוגמה":** מוריד קובץ מ-GitHub.
  - **ייצוא CSV:** שומר קובץ על המכשיר.
- **Content-Security-Policy:** מוגדר בבנייה. קוד רץ רק מהאתר עצמו, והרשת מוגבלת לשרת המפות ולקובץ הדוגמה.
- **Trusted Types:** הדפדפן חוסם הזרקת HTML שמכיל קוד (`require-trusted-types-for 'script'`, ראו [src/trustedTypes.ts](src/trustedTypes.ts)).
- **קובץ לוג מטופל כקלט עוין:**
  - בלי regex שעלול לתקוע את הדף.
  - מגבלות על גודל הקובץ, אורך שורה, מספר אפוקים, אותות ופתרונות.
  - בדיקת טווחים לקואורדינטות, לזמנים ולדיוק.
  - הגנה מפני prototype pollution.
  - שגיאה נשארת בתוך החלק שבו קרתה ולא מפילה את כל הדף.
- **הגנה מפני clickjacking:** האתר מסרב לרוץ בתוך iframe של אתר אחר.
- **הגנה מפני reverse tabnabbing:** כשהאתר נפתח מתוך אתר אחר, מופיעה אזהרה.
- **Referrer ו-noindex:** אתרים אחרים מקבלים רק את שם האתר ולא את כתובת הדף, והאתר חסום לאינדוקס במנועי חיפוש.
- **שרשרת האספקה:**
  - ה-Actions נעולים ל-commit SHA מלא.
  - ה-token של ה-workflow מקבל רק את ההרשאות שכל שלב צריך.
  - ההתקנה נעשית מה-lockfile, בלי להריץ סקריפטים של חבילות.
  - הבנייה נכשלת אם יש בחבילות פגיעות ידועה ברמת חומרה high ומעלה.
  - כל חבילה צריכה להגיע מ-registry.npmjs.org עם hash מסוג sha512 וחתימה מאומתת.
  - אין שימוש ב-cache בין ריצות.
  - CI בודק כל pull request.
  - Dependabot פותח עדכונים חודשיים, ורק לגרסאות שפורסמו לפחות 7 ימים קודם.
  - [.npmrc](.npmrc) מגן על המחשב: לא מריץ סקריפטים של חבילות ולא מתקין גרסאות טריות.

## הרצה מקומית

```bash
npm ci          # מתקין בדיוק את הגרסאות שב-lockfile, בלי סקריפטים של חבילות
npm run dev     # רק על המחשב הזה
```

שרת הפיתוח רץ ב-HTTPS עם תעודה שנוצרת מקומית, כי דפדפן בטלפון חוסם מיקום בלי HTTPS.

כדי לבדוק מהטלפון מריצים `npm run dev:phone`. השרת נפתח לכל רשת ה-Wi-Fi, אז עושים את זה **רק ברשת שסומכים עליה**. פותחים בטלפון את כתובת ה-`Network` שמודפסת ומאשרים את אזהרת האבטחה.

## פרסום

כל push ל-`main` בונה את האתר ומפרסם אותו ב-GitHub Pages דרך [.github/workflows/deploy.yml](.github/workflows/deploy.yml). צריך להגדיר פעם אחת בריפו: Settings ← Pages ← Source: **GitHub Actions**.
