# אטלס GNSS

כלי דפדפן למעקב אחרי מקלט ה-GNSS של הטלפון ולניתוח לוגים של GNSS. מותאם לטלפון, עובד גם במחשב.

## מה יש בו

**מעקב חי** (Geolocation API של הדפדפן)
- מיקום WGS84, דיוק, גובה, מהירות וכיוון. כל פתרון מוצג ברגע שמגיע, בלי מטמון.
- קצב העדכון בפועל, פיזור הפתרונות (RMS) וגרפים חיים.
- ייצוא הסשן ל-CSV, ואפשרות להשאיר את המסך דולק.

**ניתוח לוג** (הקובץ נקרא רק בדפדפן ולא נשלח לשום מקום)
- מפת שמיים ו-C/N₀ לכל אות, מי בשימוש בפתרון, מסלול, וניגון לאורך זמן.
- פורמטים נתמכים:
  - [GPSTest](https://github.com/barbeau/gpstest) ו-[GnssLogger](https://github.com/google/gps-measurement-tools): רשומות `Status`, `Fix`, `Raw` ו-`NMEA`
  - קובצי NMEA 0183 ממקלטים חיצוניים (u-blox וכו׳), כולל מזהי אותות של NMEA 4.1

**ניטור שלמות אות (שיבוש / זיוף)** (`src/integrity.ts`)
- רץ בשתי הלשוניות ומציג ציון חשד 0–100, ממצאים עם ראיות מספריות, והסבר תמים אפשרי לכל ממצא.
- **מהמיקום בלבד** (גם בדפדפן הטלפון): קפיצות בלתי אפשריות, מהירות ותאוצה בלתי סבירות, מיקום קפוא בזמן תנועה מדווחת, מהירות דופלר שלא תואמת לתזוזה, גובה בלתי אפשרי, זמן שחוזר אחורה.
- **מחיישני התנועה של הטלפון** (`src/motion.ts`, רק אחרי הסכמה, הנתונים בזיכרון בלבד): GNSS שמראה נסיעה בזמן שמד התאוצה מראה טלפון מונח; פנייה במסלול ה-GNSS שהג'ירוסקופ לא הרגיש; טלפון בתנועה כשה-GNSS קפוא. מזייף שולט במה שה-GNSS מחשב, לא בתנועה הפיזית.
- **משעון המקלט** (רשומות Raw): הסטת השעון שלא תואמת לסחיפה שהמקלט עצמו מדווח (במקלט תקין: עד כ-1 ns/s), קפיצות בקצב הסחיפה, וזמן GNSS שנפרד משעון הטלפון. השדות של 64 ביט מחושבים ב-BigInt, כי ב-Number הרזולוציה היא רק 256 ns.
- **השוואה למיקום מהרשת הסלולרית** (לוגים עם פתרונות NLP): מזייף GNSS לא משפיע על מיקום האנטנות וה-Wi-Fi. פער גדול יותר ממה שהדיוק של שניהם מסביר מסומן.
- **מתאם C/N₀ בין לוויינים:** לוויינים אמיתיים בכיוונים שונים משתנים כל אחד בנפרד, ומשדר מזייף מזיז את כולם יחד. בכויל על לוגים אמיתיים: מתאם חציוני 2–4%. בזיוף ממשדר אחד: 81%.
- **מנתוני מקלט** (לוג מ-GPSTest / GnssLogger / NMEA): קפיצות AGC (המדד הישיר ביותר לשיבוש RF), C/N₀ אחיד מדי (חתימת סימולטור), צניחת אות בכל הלוויינים יחד, פער אנטנה/בייסבנד, אובדן לוויינים פתאומי, פסילת מדידות על ידי המקלט, GPS בלבד כשהמקלט תומך ביותר, איכות פתרון ו-HDOP.
- **ציר זמן של חשד:** גרף שמראה מתי בדיוק הופיעה כל ראיה. בלוג, נגיעה בגרף או בכפתור "הצג את הרגע הזה" מעבירה את הניגון לאותו רגע.
- **נבדק על:**
  - 3 לוגים אמיתיים: ללא התראות שווא.
  - 9 לוגים שהונדסו מהם: זיוף C/N₀ אחיד, טלפורט, שידור חוזר קפוא, שיבוש AGC, משיכת שעון, הזזת זמן, קפיצות בקצב השעון, משדר יחיד (C/N₀ משותף), ופער מול מיקום הרשת. כולם זוהו.
  - 3 תרחישי חיישנים מדומים: נסיעה אמיתית עם פנייה, טלפון מונח בזמן "נסיעה", ופניות מזויפות. כולם סווגו נכון.
- הערכה היוריסטית: "חשד" אומר שהדפוס מתאים להפרעה, לא שיש התקפה.

**לוויינים בזמן אמת** (לשונית "מעקב חי", `src/LiveSats.tsx`)

דפדפנים לא חושפים את נתוני הלוויינים של המקלט בטלפון, ולכן יש שתי דרכים:
- **לוויינים חזויים** (גם באייפון):
  - **מה מוצג:** איפה כל לווייני ה-GNSS נמצאים מעליך עכשיו, כולל מפת שמיים, מספר לפי מערכת וגרף לאורך הסשן.
  - **איך זה מחושב:** במכשיר (SGP4, ‏satellite.js), מתוך המסלולים הציבוריים של CelesTrak.
  - **פרטיות:** ההורדה רק באישור, והיא כוללת את כל הלוויינים בעולם בבת אחת. המיקום שלך לא נשלח.
  - **אימות:** מול האלמנך הרשמי של GPS (משמר החופים האמריקאי), התאמה של עד 0.007°.
- **מקלט חיצוני** (Web Serial: ‏Bluetooth ב-Chrome לאנדרואיד 138+, או USB):
  - **מה מוצג:** נתונים שנמדדו בפועל, בזמן אמת: מפת שמיים, לוויינים לפי מערכת, מפת חום של C/N₀, וניטור שלמות מלא.
  - **בדיקות נוספות במצב הזה:**
    - **התאמת השמיים למסלולים:** הלוויינים שהמקלט מדווח מוצגים מעל עיגולים מקווקווים במקום שבו הם אמורים להיות. הקלטה ששודרה מחדש או סימולטור לא יתאימו לשמיים האמיתיים.
    - **שעון המקלט מול שעון הטלפון.**

> בדיקות AGC, שעון ה-Raw וההשוואה לרשת דורשות לוג מאנדרואיד (GPSTest / GnssLogger).

## פרטיות ואבטחה

- **אין שרת:** האתר הוא קבצים סטטיים. המיקום נשמר רק בזיכרון של הדף ונמחק כשסוגרים או מרעננים אותו. אין עוגיות, אין אנליטיקס ואין סקריפטים של צד שלישי.
- **מה יוצא מהמכשיר, ורק אחרי פעולה מפורשת שלך:**
  - **מפה:** כבויה כברירת מחדל. כשמפעילים אותה, נשלחות ל-OpenStreetMap בקשות לאריחי האזור שמוצג. ההסכמה נפרדת לכל לשונית ותקפה רק עד סגירת הדפדפן.
  - **הכפתור "מפה":** פותח את Google Maps עם הקואורדינטות.
  - **"קובץ לדוגמה":** מוריד קובץ מ-GitHub.
  - **ייצוא CSV:** שומר קובץ על המכשיר.
- **Content-Security-Policy:** מוגדר בבנייה. קוד רץ רק מהאתר עצמו, והרשת מוגבלת לשרת המפות ולקובץ הדוגמה.
- **Trusted Types:** הדפדפן חוסם הזרקת HTML שמכיל קוד (`require-trusted-types-for 'script'`, ראו [src/trustedTypes.ts](src/trustedTypes.ts)).
- **קובץ לוג מטופל כקלט עוין:**
  - בלי regex שעלול לתקוע את הדף.
  - מגבלות על גודל הקובץ, אורך שורה, מספר אפוקים, אותות ופתרונות.
  - בדיקת טווחים לקואורדינטות, לזמנים ולדיוק.
  - הגנה מפני prototype pollution.
  - שגיאה נשארת בתוך החלק שבו קרתה ולא מפילה את כל הדף.
- **הגנה מפני clickjacking:** האתר מסרב לרוץ בתוך iframe של אתר אחר.
- **הגנה מפני reverse tabnabbing:** כשהאתר נפתח מתוך אתר אחר, מופיעה אזהרה.
- **Referrer ו-noindex:** אתרים אחרים מקבלים רק את שם האתר ולא את כתובת הדף, והאתר חסום לאינדוקס במנועי חיפוש.
- **שרשרת האספקה:**
  - ה-Actions נעולים ל-commit SHA מלא.
  - ה-token של ה-workflow מקבל רק את ההרשאות שכל שלב צריך.
  - ההתקנה נעשית מה-lockfile, בלי להריץ סקריפטים של חבילות.
  - הבנייה נכשלת אם יש בחבילות פגיעות ידועה ברמת חומרה high ומעלה.
  - כל חבילה צריכה להגיע מ-registry.npmjs.org עם hash מסוג sha512 וחתימה מאומתת.
  - אין שימוש ב-cache בין ריצות.
  - CI בודק כל pull request.
  - Dependabot פותח עדכונים חודשיים, ורק לגרסאות שפורסמו לפחות 7 ימים קודם.
  - [.npmrc](.npmrc) מגן על המחשב: לא מריץ סקריפטים של חבילות ולא מתקין גרסאות טריות.

## הרצה מקומית

```bash
npm ci          # מתקין בדיוק את הגרסאות שב-lockfile, בלי סקריפטים של חבילות
npm run dev     # רק על המחשב הזה
```

שרת הפיתוח רץ ב-HTTPS עם תעודה שנוצרת מקומית, כי דפדפן בטלפון חוסם מיקום בלי HTTPS.

כדי לבדוק מהטלפון מריצים `npm run dev:phone`. השרת נפתח לכל רשת ה-Wi-Fi, אז עושים את זה **רק ברשת שסומכים עליה**. פותחים בטלפון את כתובת ה-`Network` שמודפסת ומאשרים את אזהרת האבטחה.

## פרסום

כל push ל-`main` בונה את האתר ומפרסם אותו ב-GitHub Pages דרך [.github/workflows/deploy.yml](.github/workflows/deploy.yml). צריך להגדיר פעם אחת בריפו: Settings ← Pages ← Source: **GitHub Actions**.
